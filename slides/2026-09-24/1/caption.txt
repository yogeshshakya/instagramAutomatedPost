Developers love `map()` because it looks clean and modern. But under the hood, calling a function on every single iteration comes with hidden overhead that a classic `for` loop completely skips!

• `map()` creates a new array and invokes a callback function for every single element.
• In massive data sets or 60fps animations, this callback overhead adds up and causes GC pressure.
• A classic `for` loop doesn't allocate extra memory or require context switching.
• Use `map()` for readability in 99% of React apps, but reach for `for` when performance is strictly critical.
